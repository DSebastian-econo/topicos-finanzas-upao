# Semana 6: Riesgo y rendimiento en los mercados financieros

**Curso:** Tópicos de Finanzas Avanzadas (ECON-421, UPAO 2026-20)
**Mapeo CFA:** CFA L1 · PM: *Portfolio Risk and Return I* (base) · puente a CFA L2 PM: *Measuring and Managing Market Risk*

## Objetivos de aprendizaje

- Calcular retorno esperado, varianza, desviación estándar, covarianza y correlación.
- Explicar el efecto diversificación y distinguir riesgo sistemático de idiosincrático.
- Analizar portafolios simples de dos y más activos.

## Práctica en Python

Retornos y volatilidades de un universo BVL + US, matriz de correlaciones y efecto diversificación. **Esta semana se entrega el TR1** (informe de valoración de una empresa por DCF y múltiplos, vía fork + commit + push).
