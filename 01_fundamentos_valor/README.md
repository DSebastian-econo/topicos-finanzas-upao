# Semana 1: Fundamentos de la valoración financiera

**Curso:** Tópicos de Finanzas Avanzadas (ECON-421, UPAO 2026-20)
**Mapeo CFA:** CFA L2 · Equity: *Equity Valuation: Applications and Processes* (+ repaso L1: VPN y creación de valor)

## Objetivos de aprendizaje

- Explicar el concepto de valor intrínseco y distinguirlo del precio de mercado.
- Describir el proceso de valoración: entender el negocio, proyectar, elegir el modelo, convertir estimados en decisión.
- Relacionar riesgo, retorno y valor a través de la tasa de descuento.
- Dejar operativo el entorno del curso (Python + VS Code + Git/GitHub) y publicar el primer notebook.

## Práctica en Python

Funciones de VP/VPN/TIR en Python, descarga de primeros datos reales (yfinance + API BCRPData) y gráfico precio vs. valor.
